# Captures 0.0.2

[简体中文](0.0.2.md) · **English**

October 22, 2026, build 10.

## What's new

**Settings → About** now includes a GitHub repository link, displaying the full URL: `https://github.com/KunZhang1997/Captures`. Click it to open the repository in your default browser. The link is available in both Chinese and English, with an underline and an external-link icon.

[Download the installer](https://github.com/KunZhang1997/Captures/releases/download/v0.0.2/Captures-0.0.2.dmg) · [All releases](https://github.com/KunZhang1997/Captures/releases)

Requires macOS 14+. The universal app supports Apple silicon and Intel Macs. Open the DMG and drag Captures into Applications. When updating, quit the old version before replacing it. Updates currently require a manual download.

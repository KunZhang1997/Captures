## Installation

Requires macOS 14 or later. The same universal installer supports Apple silicon and Intel Macs. Open the DMG, drag Captures into Applications, then launch it from Applications. Grant Screen Recording permission on first use; Accessibility permission is optional. Captures runs in the menu bar.

Features include region, window, and full-screen capture, quick selection annotations, manual scrolling capture, on-device OCR, floating screenshots, image editing, and local history. The interface supports Simplified Chinese and English. Updates currently require downloading a new installer manually.

## Feedback

This is the first public preview. Automated and installer checks do not replace complete acceptance testing on other Macs. Multiple displays, different permission combinations, extended scrolling, VoiceOver, and Reduce Motion still need further verification. Report issues with your system version, reproduction steps, and examples without personal information in [Issues](https://github.com/KunZhang1997/Captures/issues).

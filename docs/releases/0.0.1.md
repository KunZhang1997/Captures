## 安装

需要 macOS 14 或更新版本。Apple 芯片和 Intel Mac 使用同一个通用安装包。打开 DMG，把 Captures 拖入应用程序，再从应用程序启动。首次使用时授予屏幕录制权限；辅助功能权限为可选。应用常驻菜单栏。

提供区域、窗口、全屏截图，选区快速标注、手动长截图、本机 OCR、悬浮对照、图片编辑和本地历史记录。支持简体中文与英文。目前通过手动下载新安装包更新。

## 使用反馈

这是首次公开试用版本。自动化与安装包检查不能替代外部 Mac 的完整使用验收；多屏、不同权限组合、长时间滚动、VoiceOver 与减少动态效果仍需要进一步验证。遇到问题可在 [Issues](https://github.com/KunZhang1997/Captures/issues) 提供系统版本、复现步骤和不含个人信息的示例。
